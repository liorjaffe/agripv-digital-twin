# Archived experiments

`legacy/Agrivoltaic system modeling.py` is a superseded adaptation of a pvlib
gallery example for a different site. Its PAR conversion, crop-moisture ratio,
and nighttime growth handling conflict with the canonical model and must not be
used to reproduce project results.

The PNGs previously generated by that script have been removed from version
control because their calculations are not canonical. Use the current
[`project/scenarios/`](../project/scenarios/) pipelines and tagged-release
reports instead.

The project-level MIT license does not replace any upstream terms that apply
to this adapted gallery example. Verify its upstream attribution and license
before redistributing the archived script.
